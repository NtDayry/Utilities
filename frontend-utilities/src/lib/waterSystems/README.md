# ถังน้ำ / บ่อเก็บน้ำที่เพิ่มจากหน้าเว็บ

ปุ่ม "เพิ่มระบบ" ในหน้าภาพรวมระบบน้ำ (admin) เพิ่มได้ 2 ชนิด: ถังน้ำ และบ่อเก็บน้ำ
บ่อน้ำประปา + ระบบปั๊มของโรงงาน และ Purified Water เป็นหน้าตายตัว ไม่ใช้ระบบนี้

## ขั้นตอน

1. กด "เพิ่มระบบ" → หน้าต่างเชื่อมต่อ: เลือกชนิด ตั้งชื่อ, MQTT Broker (เริ่มจากค่าพื้นฐาน แก้ได้) + Topic → "เชื่อมต่อ"
2. เชื่อมต่อสำเร็จ → สแกนข้อความที่เข้ามา → เลือกตำแหน่งค่าระดับน้ำ, หน่วย, เกณฑ์ต่ำ–สูง → "สร้าง"
3. หน้าของระบบ (`/water-supply/systems/:systemId`) เปิดแผง "ตั้งค่า" ให้: จำนวน/รูปทรง/ขนาดถัง, เซ็นเซอร์เพิ่ม, ปั๊ม

ทุกค่าที่แสดงระบุ "ตำแหน่งของข้อมูล" ใน JSON เอง (เช่น `water_level.level_cm`) จึงไม่ผูกกับ firmware ตัวใด
- เซ็นเซอร์: ระดับน้ำ, มิเตอร์น้ำวัดปริมาณที่ใช้ไป, มิเตอร์น้ำวัดอัตราการไหล, วาล์วน้ำเข้า — เปิดใช้แล้วต้องระบุตำแหน่งของข้อมูล
- ปั๊ม: inverter หรือ magnetic + ตำแหน่งของข้อมูล — ชี้ไปที่ก้อนข้อมูล (เช่น `pump1` ที่มี `running`, `freq`, `current`, `alarm`) หรือชี้ไปที่ค่าเดิน/หยุดโดยตรง (เช่น `controls.pump1_on`)

## ไฟล์

- `model.ts` ตรรกะแบบ pure: ค่าตั้งต้น, สแกนข้อความ, อ่านค่าตามตำแหน่ง, ปริมาตร N ใบ (สูตรเดียวกับ `lib/tankCalculations.ts`), สถานะรวม, ตรวจ/ซ่อมข้อมูล
- `mqttTopics.ts` ข้อมูลสดแยกตาม (broker, topic) ใช้การเชื่อมต่อร่วมกันต่อ broker
- `repository.ts` ที่เก็บรายการระบบ: ตอนนี้ localStorage (`utilities-water-systems-v2`) ย้ายไป API ได้โดยแก้ไฟล์นี้ไฟล์เดียว
- `lib/tankScene3d.ts` + `components/water-supply/TankLevel3D.tsx` ภาพ 3 มิติ แสดงเฉพาะระดับน้ำ วาดตามจำนวน/รูปทรง/ขนาด
- `components/water-supply/WaterSystemConnectModal.tsx` หน้าต่างเชื่อมต่อ, `WaterSystemSettings.tsx` แผงตั้งค่าในหน้า, `WaterSystemFormParts.tsx` ชิ้นส่วนฟอร์ม
- `store/waterSystems.ts` สถานะกลาง + Audit Log (entity `water_system`)

## ข้อจำกัด

- รายการระบบ (รวมชื่อผู้ใช้/รหัสผ่านของ broker ที่กำหนดเอง) เก็บใน localStorage ของเบราว์เซอร์แต่ละเครื่อง ไม่เข้ารหัส
- broker ที่กำหนดเองต้องเปิด MQTT over WebSocket และหน้าเว็บ HTTPS ต่อได้เฉพาะ `wss://`
- โหมด dev: เฉพาะ broker พื้นฐานที่รับผ่าน bridge ใน `vite.config.ts`
- แนวโน้มระดับน้ำเก็บในหน่วยความจำตั้งแต่เปิดหน้า ไม่ใช่ข้อมูลย้อนหลัง
